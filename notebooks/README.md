# Notebooks

Use this folder for exploratory notebooks that mirror the production training
workflow in `src/train.py`.

Suggested notebook sections:

1. Load MovieLens ratings and movie metadata.
2. Inspect matrix sparsity and rating distribution.
3. Create the leave-one-relevant-rating-out evaluation split.
4. Train biased matrix factorization.
5. Compare precision@K, recall@K, hit rate@K, and catalog coverage.
6. Generate recommendations for sample users.
